# Custom Capture Strategy

## Purpose

Represent a personalized capture-first note-taking method where reducing friction at the moment of capture is more important than forcing information into a complete structure immediately.

This strategy exists as an explicit extension point for a user's own conventions rather than pretending that a standard method such as Zettelkasten, PARA or Cornell fits every existing note system.

## Principles

- Make capture fast enough that useful information is not lost because organization is inconvenient.
- Preserve the original content/source before applying AI transformations.
- Apply only the minimum metadata/classification required at capture time.
- Allow later processing to classify, connect, summarize or promote notes when useful.
- Keep user-owned notes authoritative; derived AI metadata remains replaceable.
- Evolve conventions from actual retrieval/use rather than designing taxonomy for its own sake.

## Example flow

`capture immediately -> preserve source -> minimal metadata -> later processing -> connect/classify/distill when useful -> retrieve/use`

## Specialization

Concrete personalized conventions — capture syntax, folders, filenames, tags, applications, shortcuts and processing rules — belong to a private profile or a more specific strategy specialization. This public strategy intentionally defines only the reusable capture-first philosophy.
