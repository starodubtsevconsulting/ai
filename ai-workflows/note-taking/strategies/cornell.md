# Cornell Strategy

## Purpose

Capture structured notes for learning/review using a main note area, cues/questions and a concise summary.

## Principles

- Record the main material during capture/learning.
- Derive cues, questions or key concepts after capture.
- Summarize the material concisely in your own words.
- Review by using cues/questions to recall the underlying material rather than only rereading.
- Refine notes when review exposes gaps in understanding.

## Example flow

`capture main notes -> derive cues/questions -> summarize -> review/recall -> refine gaps`

The exact page/template representation is an implementation detail.
